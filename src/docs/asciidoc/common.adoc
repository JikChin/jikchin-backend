== 공통

=== 인증

로그인이 필요한 API는 `Authorization` 헤더에 Access Token을 담아 요청합니다.

[source,http]
----
Authorization: Bearer {access-token}
----

=== 응답 형식

모든 응답은 `ApiResponse` 형태로 감싸져 있습니다.

|===
| 필드 | 타입 | 설명

| `resultType`
| String
| `SUCCESS` 또는 `ERROR`

| `data`
| Object
| 성공 시 응답 데이터. 실패 시 `null`

| `error`
| Object
| 실패 시 에러 정보. 성공 시 `null`
|===

.실패 응답 예시
[source,json]
----
{
  "resultType" : "ERROR",
  "data" : null,
  "error" : {
    "errorCode" : "E2003",
    "message" : "이미 평가한 멤버입니다.",
    "errorData" : null
  }
}
----

=== 에러 코드

실패 응답의 `error.errorCode` 값입니다.

NOTE: `E1001`~`E1003`은 컨트롤러가 아니라 보안 필터(인증·인가 실패)가 같은 형식으로 응답합니다. 입력 검증 실패와 일부 예외는 아직 이 형식으로 응답하지 않습니다.
