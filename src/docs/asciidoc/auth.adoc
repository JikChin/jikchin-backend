[[auth]]
== 인증

인증 API는 `Authorization` 헤더 없이 호출합니다. 토큰 만료 시각은 UTC 기준 ISO-8601 문자열(`Z` 접미사)입니다.

[[auth-signup]]
=== 회원가입

회원을 만들고 바로 로그인된 상태의 토큰 쌍을 발급합니다.

operation::auth-signup[snippets='http-request,request-fields,http-response,response-fields']

[[auth-login]]
=== 로그인

이메일과 비밀번호로 로그인해 토큰 쌍을 발급합니다.

operation::auth-login[snippets='http-request,request-fields,http-response,response-fields']

[[auth-refresh]]
=== 토큰 재발급

Refresh Token으로 새 토큰 쌍을 발급합니다.

operation::auth-refresh[snippets='http-request,request-fields,http-response,response-fields']

[[auth-logout]]
=== 로그아웃

Refresh Token을 폐기합니다. 응답의 `data`는 항상 `null`입니다.

operation::auth-logout[snippets='http-request,request-fields,http-response,response-fields']
