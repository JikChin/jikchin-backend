[[admin-report]]
== 관리자: 신고

`ROLE_ADMIN` 회원만 호출할 수 있습니다.

[[admin-report-list]]
=== 신고 목록

신고를 오래된 순 커서 페이징으로 조회합니다. 다음 페이지는 응답의 `nextCursor`를 `cursor`로 넘겨 요청합니다. 페이지 마지막 신고를 처리해 상태가 바뀌어도 그 `nextCursor`로 다음 페이지를 이어 읽을 수 있습니다.

operation::admin-report-list[snippets='http-request,request-headers,query-parameters,http-response,response-fields']

[[admin-report-resolve]]
=== 신고 처리

`PENDING` 신고를 `RESOLVED`로 바꿉니다. 이미 처리된 신고는 `E3005`로 응답합니다.

operation::admin-report-resolve[snippets='http-request,request-headers,path-parameters,http-response,response-fields']

[[admin-report-reject]]
=== 신고 반려

`PENDING` 신고를 `REJECTED`로 바꿉니다. 이미 처리된 신고는 `E3005`로 응답합니다.

operation::admin-report-reject[snippets='http-request,request-headers,path-parameters,http-response,response-fields']
